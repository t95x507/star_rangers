# Звёздные Рейнджеры P2P

Браузерная кооперативная космическая стратегия в духе «Космических рейнджеров 2» на three.js
с P2P-мультиплеером через WebRTC (PeerJS). Сервер не нужен — подходит статический хостинг вроде GitHub Pages.

## Запуск на GitHub Pages

1. Создайте репозиторий и положите в корень все файлы (`index.html`, `style.css`, `js/`, `.nojekyll`).
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Откройте `https://<ник>.github.io/<репо>/`, нажмите «Создать игру» и отправьте друзьям ссылку «копировать ссылку».

Локально: `python -m http.server` в папке проекта и открыть http://localhost:8000 (с `file://` ES-модули не работают).

## Как устроено время

- **1 ход = 1 день.** Все отдают приказы одновременно, хост просчитывает день для всех сразу и рассылает анимацию.
- **Время идёт само.** День наступает каждые 10 секунд (хост меняет: 5–60 с или «∞ ждать всех»),
  даже если кто-то ещё не отдал приказ. Большой таймер сверху по центру показывает, сколько осталось.
- **Ускорение — только по согласию всех.** Пробел (кнопка «Ускорить время») переключает флаг ускорения,
  он сохраняется между ходами. Когда флаг включён у всех игроков онлайн, дни идут подряд без пауз, анимации стыкуются.
  Нажал ещё раз — флаг снят, мир снова ждёт полный таймер.
- Если рядом с игроком враг, его флаг ускорения сам сбрасывается, чтобы бой не промотался.
- **Пауза.** Когда все игроки онлайн сидят на планетах или стоят в космосе без приказа, время стоит. В момент паузы ускорение у всех сбрасывается. Пробел хотя бы у одного игрока снова пускает время по таймеру, у всех — без задержек. Приказ или взлёт тоже снимает паузу.
- **Календарь.** Над таймером — игровая дата и время (с 1 января 3301), часы идут во время анимации хода.
- Торговля, верфь, ремонт и заправка на планете — мгновенные действия, они не тратят ход.

## Сеть

- Хост — авторитетный: симуляция идёт только у него, клиенты шлют приказы и получают состояние.
- Хост автоматически сохраняет игру в localStorage каждый ход («Продолжить сохранённую»).
  Игрок, переподключившийся с тем же именем, получает свой корабль обратно.
- Сигналинг идёт через бесплатный публичный брокер PeerJS, дальше трафик идёт напрямую между браузерами.
  У некоторых провайдеров или за строгим NAT прямое соединение может не установиться (нужен TURN-сервер).

## Управление

ЛКМ — приказ (планета: сесть, враг: атаковать, контейнер: подобрать, пустота: лететь) ·
ПКМ — сдвиг камеры · колесо — зум · СКМ — вращение · **Пробел** — конец хода · **M** — карта · **I** — корабль и трюм ·
**F** — к своему кораблю · **Enter** — чат · **Esc** — снять выделение.
